# handcrafted-haven

Handcrafted Haven is a web application that connects artisans and crafters with
customers who want to discover and purchase unique handcrafted items. It supports
seller profiles, product listings, and reviews/ratings, with a focus on community,
sustainability, and supporting local creators.
